# Regional Sales Dashboard | Power BI

An interactive **regional sales performance** dashboard developed in Microsoft Power BI. This project presents sales information through visual reporting to support comparisons across geographic regions and business performance exploration.

## Project overview

The report is designed to make regional sales information easier to explore, compare, and communicate. It demonstrates how a Power BI dashboard can turn tabular business data into an accessible visual reporting experience.

## Analysis focus

- Regional sales performance and comparison
- Visual exploration of sales information
- Interactive filtering and report navigation, where available
- Review of the underlying report pages and data model

> Specific KPIs, geographic fields, and business dimensions should be confirmed from the PBIX data model and report pages before drawing conclusions.

## Tools and techniques

- **Microsoft Power BI Desktop** — report development and visualization
- **Power Query** — data preparation, where used in the report
- **DAX** — measures and calculations, where implemented

## Open the project

1. Download or clone this repository.
2. Install and open **Power BI Desktop**.
3. Open `Regional Sales Sample.pbix`.
4. If Power BI prompts for a missing source, reconnect the required dataset or update the source path, then refresh.
